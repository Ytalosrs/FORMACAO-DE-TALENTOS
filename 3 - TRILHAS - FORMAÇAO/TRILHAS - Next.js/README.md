# Next.js — Trilha de Conhecimento

Bem-vindo ao repositório **Next.js-Guia**! 👋

Este repositório foi criado com o objetivo de centralizar conhecimentos, exemplos práticos e desafios relacionados ao desenvolvimento de aplicações utilizando **Next.js**.

O material foi desenvolvido a partir dos conhecimentos absorvidos nos estudos realizados na trilha oficial de aprendizado da **Vercel Academy**, com explicações complementares, exemplos e exercícios próprios para apoiar o aprendizado e a evolução técnica dos integrantes da equipe.

## 📚 Curso de referência

Esta trilha foi desenvolvida a partir do seguinte curso:

🔗 [Next.js Foundations | Vercel Academy](https://vercel.com/academy/nextjs-foundations)


Nesta trilha, a versão utilizada foi o **Next.js 16**.
